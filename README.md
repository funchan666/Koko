# Koko

SwiftUI 原生 iOS 社交应用，本地交互预览版。最低 iOS 16.0，支持 iPhone / iPad。直接打开 `Koko.xcodeproj`；工程生成来源为 `project.yml`。

## 当前功能

| 模块 | 页面与本地行为 |
| --- | --- |
| 账号 | 启动动效、单页欢迎入口、协议勾选、独立邮箱登录/注册、真实 Apple 授权、资料完善、相册/拍照头像、协议 WebView |
| 发现 | 推荐/关注内容、分类、创作者、房间入口、综合搜索、类型/年龄/地区/语言/性别筛选 |
| 内容 | 44 张照片、10 段视频、自定义播放/暂停/静音/跳转控制、作者主页、点赞、收藏、评论、删除自己的评论、举报与隐藏 |
| 房间 | 语音/视频房列表、创建房间、封面/话题/席位/公开状态/人数目标、上麦下麦、静音、主持人与管理员操作、房间聊天、快捷发言、观众、贡献记录、音乐、更多房间、离开确认 |
| 关系与消息 | 关注/取消、关注与粉丝列表、显式示例互关、好友房间、聊天搜索、文本/照片附件与大图查看、草稿、会话清理、通知已读、独立语音/视频通话准备页、互关限制、真实麦克风授权及输入检测、音频路由、摄像头开关及翻转 |
| 我的 | 编辑资料、原创插画头像与真实照片相册、收藏、签到、等级、实时金币余额、九档 Apple 内购、流水、礼物商店、背包、佩戴与赠送 |
| 设置 | 隐私、通知偏好、本地每日提醒、存储、反馈、本地举报/拉黑/解除、账号切换、退出、删除本地账号 |

所有内容、房间和示例人物只用于本地体验。示例互关须从人物主页主动开启，应用不会伪装真实用户关注或自动发消息。通话摄像头只在设备预览，不录制、不传输；资料页可由用户主动拍摄照片，头像仅保存在本机。在用户主动准备通话或连麦时请求真实麦克风权限，授权后仅在内存中检测输入音量，不保存录音、不传输音频。静音、离开和后台时停止输入。

## 原创设计与素材

Koko 使用薄荷、深墨绿与柔白的独立视觉方向，采用 Avenir Next 排版。应用内背景、面板、按钮、导航图标、装饰、礼物及头像占位均来自本项目 Image 2 原创位图。无 SF Symbols、图标库、Canvas、SVG、Core Graphics 绘图或默认系统导航/弹窗/列表外观。SwiftUI 仅承载布局、文字、输入、交互和图片展示；Apple 授权、权限与系统键盘保留平台原生行为。

素材目录：`Koko/Resources/KokoArtwork.xcassets`。

- `KokoNavigation`：16 个原创操作图标。
- `KokoSurfaces`：6 个原创背景与可拉伸控件底图。
- `KokoScenes`：4 张原创场景和空状态插画。
- `KokoCollection`：4 个头像、4 个内容占位、8 个礼物/物品，共 16 张。
- `AppIcon`：独立原创 Koko 图标。
- `KokoSocialWelcome`：原创三位成年人物的视频交流拼贴主视觉，用于新版欢迎页。
- `KokoWelcomeControls`：透明底登录按钮与协议勾选素材；仅裁取原图区域，不以代码绘制。
- `KokoArrival`：原创薄荷唱片、听筒、迎宾门与入场卡片，用于启动、欢迎入口、通话页面、登录过渡和协议提示。

原有 43 个位图画面元素，另新增 `KokoFirstRecord` 原创唱片欢迎礼，用于首次赠币弹窗与充值页主视觉。原始图集被保留，应用只裁取已生成的图块并缓存，不通过代码生成美术。提示词保存于 `garden-gpt-image-2/prompt/`，不会打入 App。

已评估 Taste、Design 和 Garden：Taste 的网页落地页流程不适用于本原生多步骤应用；采用 Design 的原创视觉方向约束，Garden / `gpt-image-2` Host-Native 及 `imagegen` 生成原创素材。未采用 HTML 替代原生实现。

## 数据与演示边界

- `CommunityMember`、`ListeningRoom`、`SharedMoment`、`RoomKeepsake`、`PersonalJournal` 等按业务职责独立建模。
- 邮箱登录按用户最新要求仅校验有效邮箱格式和 8–128 字符非空白密码，不需要提前注册或匹配历史密码。新邮箱自动创建本地资料，已有邮箱恢复原有数据，未完成资料继续填写。注册入口保留重复密码确认；新登录/注册不存储密码或校验值。旧 Keychain 数据不再用于登录，删除对应本地账号时仍清理旧记录。当前没有邮箱验证、邮件找回或跨设备账号服务。
- 每个账号的资料、关系、房间、评论、会话、物品、金币钱包和已验证交易独立存放于 Application Support/KokoCommunity 的 JSON 文件；采用原子写入和文件保护。保存失败保留原状态并展示可读提示。
- 金币充值通过真实 StoreKit 2；只有点某档 Buy 才请求该商品。验证 Apple 交易、匹配 appAccountToken，余额和交易去重记录原子落盘后才 finish。支持取消、pending、未到账重试和收到的退款调整；没有模拟成功分支。
- 新建本地账号首次完成资料进入首页赠送 600 金币并展示原创唱片欢迎动效。正常重登不重复赠送，同一安装内删除后重建同一身份也不重复赠送。聊天始终免费；可选礼物及装饰的消费需要明确确认，不足自动进入充值页。
- 旧的演示金币余额与流水归档保留，不转换成可消费金币。新字段均为可选值，兼容旧账号 JSON。
- 当前账户体系与钱包仍按此前范围保存在本机，没有生产认证、服务端余额、防篡改账本或跨设备同步。不可宣称已具备服务端支付闭环；上线前需接入正式账号和服务端交易/余额对账。删除本地资料会删除剩余金币与已完成订单记录，页面明确说明这一影响。
- 举报和反馈保存在本地；界面明确说明未提交给审核/客服服务。
- Apple 授权代码及 entitlement 已接入，但需要用户的正式 Bundle ID、开发者团队与 Sign in with Apple 配置。它不生成虚构的后端 Token。
- 通话连接状态是本地预览，真实通信服务后续接入。摄像头由用户主动开启，离开页面/进入后台停止；模拟器没有摄像头时提示不可用。

用户提供的 `photos/` 共 **44 张照片（43 JPG + 1 WebP）**、`videos/` 共 **10 段 MP4** 已全部进入内容目录，没有抽样或截断。原文件保留原名、不修改内容，以文件夹引用打入应用。视频保留原始音轨。

- 发现页默认交错展示全部 54 条内容，可切换照片/视频，继续使用话题、关注、搜索和收藏功能。
- 每条内容可查看图片或播放视频、点赞、收藏及评论。内容归于明确标注的示例策展账号，不声称照片中人物就是该账号。
- 相册和聊天附件可选择全部 44 张照片，添加、预览和删除只影响本地记录。旧相册插画和旧聊天附件仍可读取；新增的持久化字段为可选字段，兼容此前 JSON。原四个内容位保留内容键，使已有收藏、点赞和评论随占位媒体替换继续可用。
- 视频列表只加载提取的封面，不创建播放器；详情按需创建 AVPlayer，支持暂停、静音、前后 10 秒、结束后重播、失败提示与重新加载。离开详情、打开举报面板或进入后台时停止/暂停播放。
- 列表采用最长边 640px 缩略图；详情按显示用途降采样，后台解码并限制缓存，避免同时解码全部原图。WebP 另生成 JPEG 展示副本，原 WebP 保留。

内容标题和话题维护在 `ContentLibrary/collection-notes.json`；完整逐项清单在 `Koko/Resources/CommunityMedia/community-media.json`，包含每个源文件名、SHA-256、预览文件名、尺寸及视频时长。应用直接读取该目录，不以文件夹里“存在文件”代替页面接入。

以后增加或调整媒体时，补全对应内容记录，执行 `python3 scripts/prepare_community_media.py` 生成缩略图与内容目录，再用 XcodeGen 更新工程。脚本使用本机 Pillow 与 ffmpeg/ffprobe，只准备媒体资源，不构建或运行应用。

房间仍为本地互动预览，素材视频不会冒充真实直播或远端视频通话。房间背景音乐尚未提供：预留 `koko-window-seat.mp3`、`koko-slow-afternoon.mp3`、`koko-last-train-home.mp3`，缺少文件会明确提示。

## 登录与入场流程（2026-10-08）

- 启动显示约 1.6 秒原创唱片动效；未登录时直接进入单页欢迎入口，可选择邮箱登录、注册或 Apple 登录，不再展示多页引导。已有会话直接恢复，资料未完成则继续填写。
- 欢迎入口、邮箱登录和注册底部均有未预选的双协议同意项。未同意点击下一步会显示深绿薄荷色的简短协议提醒；本地记录同意版本及时间。旧会话缺少当前同意记录时补充勾选。
- [用户协议](https://sites.google.com/view/koko-terms-of-service/about)与[隐私协议](https://sites.google.com/view/koko-privacypolicy/about)在 WKWebView 中打开，保留返回、重试和加载失败提示。
- 有效表单提交后显示独立的入场卡片展开动效，固定约 3.6 秒，再执行本地格式校验与资料保存；不会用假进度声称已联网认证。启用“减少动态效果”时降低动画。
- Apple 按钮调用 AuthenticationServices 真实授权；取消不进入下一步，成功后进入资料页。首次 Apple 返回姓名时保存并自动填入，已编辑的名字不会被后续授权覆盖。启动及回到前台检查 Apple 授权状态，已撤销或失效时返回登录。
- 资料必填显示名、性别（可选不透露）、国家/地区、有效生日（18 岁以上）和至少一个兴趣；简介可选。头像支持系统 PhotosPicker 或实际拍照，并保留四个原创插画选项。照片压缩为最长边 900px 的 JPEG，不复制原始照片元数据。
- 本地资料、登录状态和头像持久保存；照片在 Application Support/KokoPortraits。替换头像和删除账号会清理旧照片。没有开启完整相册扫描、照片自动上传或自动拍照。
- Apple 授权与相册选择使用真实平台界面；Koko 的按钮、页面、协议弹窗和过渡均为原创主题布局与位图素材。苹果真实登录仍需正式签名及 App ID 服务配置，本轮未运行验证。

## 语音、视频与房间连麦补全（2026-10-08）

已只读核对本机 Nana 的视频页、互关门槛、房间申请/取消/等待、摄像头开关和翻转功能。Nana 对应源码注明没有 RTC 或信令传输，因此 Koko 继续遵守当前本地交互范围，不显示虚假接通或远端通话时长。没有修改 Nana，也没有复用它的代码或美术。

- 人物主页、好友列表、聊天详情同时提供 Voice call / Video call；非互关时先展示原创主题说明，禁止提前获取设备权限。
- 准备语音/视频、开启麦克风和申请连麦会调用真实系统授权（iOS 17+ AVAudioApplication，iOS 16 AVAudioSession）；Info.plist 已加入 NSMicrophoneUsageDescription。拒绝时展示原因及系统设置入口。浏览页面不自动索取麦克风权限。
- AVAudioEngine 对输入做实时音量检测，显示百分比；不写入录音文件，不回放自己的声音，不发送媒体。静音真正停止输入；扬声器按钮切换实际 AVAudioSession 输出路径，显示当前音频设备。
- 视频提供本机预览、关闭摄像头、前后翻转、权限拒绝设置入口。摄像头不会抢占麦克风的音频会话配置。
- 房间 Connection 面板提供申请、等待计时、取消、显式尝试本地席位、麦克风/视频控制、下麦和结束。等待时间明确是本地等待，不模拟对方接听；没有 RTC 时不会自动推进到真实接通。
- 离开/结束/进入后台会关闭音视频；系统中断和耳机连接变化会暂停输入，重新启用由用户主动触发。个人席位静音状态与本机采集同步，下麦清理席位残留静音标记。
- 聊天、语音和视频入口以及房间连麦全部免费。真实跨设备呼叫仍需后续接入 RTC 服务、信令及服务端授权。

这轮只做源码、工程引用、权限配置与资源检查，未编译、测试或启动应用。
