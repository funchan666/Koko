# Koko safety and review receipts

Two original raster surfaces created using Garden / gpt-image-2 Host-Native and
imagegen. Design: warm paper, mint/coral accents and a small semantic embossed
seal. Success uses a speech/check seal; waiting for review uses an envelope and
pending dot. No character illustrations, stock icons, coded drawing or cropping.

The prompt files capture the exact art direction. artwork-provenance.json records
paths and SHA-256 hashes. Original full outputs live in assets/original-ui and are copied
unchanged to the app asset catalog. SwiftUI supplies live localized text, actions,
accessibility and scrolling; the artwork contains no baked-in status copy.

Taste/Design/Garden routing was evaluated. Native SwiftUI is preserved; browser and
HTML deliverable workflows were not forced onto this task. Generated artwork was
inspected, but application rendering was not run under the no-build/run agreement.
