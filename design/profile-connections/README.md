# Profile connections refresh

The member page keeps one cover photo, a concise biography and illustrated interests. A compact conversation area contains messaging plus two original call buttons. Moments use a two-column collection (one column at accessibility text sizes). Counts come from visible content. The More action in the upper-right opens report and block actions; the duplicate footer action and repetitive explanation paragraphs are removed.

Voice and video button artwork was generated independently for Koko using Garden / Image 2 Host-Native image generation. The full original PNGs are stored in `assets/original-ui/profile-connections/` and copied unchanged into their image sets. Labels remain native, localized and accessible. Prompts and source hashes accompany this note.

Existing mutual-follow call checks, permissions, follow persistence and safety storage are preserved. Verification is limited to source, asset references, localization references and Git diff checks. No build, tests, analyzer, simulator or device run was performed.
