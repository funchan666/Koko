# Personal collection and account tools

The requested lower portion of Personal Space now uses two compact groups: a collection card with three semantic artwork buttons, followed by a grouped account-tools card. Descriptions sit below their labels; sign-out belongs to the tools group and keeps the existing confirmation and real session-clearing/loading flow.

Four original raster assets were created with the built-in image tool through Garden Host-Native. The three objects are the interactive keepsake, backpack and level buttons. One quiet mint surface is shared by the groups. No people, title illustrations, programmatically drawn decoration, or stock/system icons were added. Assets are copied without cropping, recoloring or other pixel edits.

See [asset and prompt manifest](assets.json) for every final asset path, original output and generation prompt. Dark and cream tools-surface explorations were rejected and are not app resources.

Native labels retain the existing five-language resources. Collection actions stack at accessibility text sizes; menu descriptions wrap and rows grow with text. Existing shop, backpack, level, settings, block list and feedback destinations remain wired.

Validation: source/diff inspection, asset-name and catalog JSON checks, original/source hash comparison. Generated artwork was visually inspected. No compilation, tests, analyzer, simulator or device execution was performed; the assembled native screen has not been runtime verified.
